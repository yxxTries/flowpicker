Conflicts & caveats

  • GitHub Copilot does not officially support Helix.
  • Continue.dev only supports VS Code and JetBrains — your IDE is Helix.
  • Codeium does not officially support Helix — use VS Code, JetBrains, Vim, or Neovim.
  • Cursor built-in only runs inside the Cursor editor — your IDE is Helix.
  • Cline only supports VS Code and JetBrains IDEs — your IDE is Helix.
  • Windsurf Cascade only runs inside Windsurf — your IDE is Helix.
  • Sourcegraph Cody does not officially support Helix — use VS Code, JetBrains, or Visual Studio.
  • Tabnine does not officially support Helix.
  • Amazon Q Developer does not officially support Helix — use VS Code or JetBrains.
  • JetBrains AI Assistant only runs inside JetBrains IDEs — your IDE is Helix.
  • Qodo officially supports VS Code and JetBrains — your IDE is Helix.
  • Supermaven only supports VS Code, JetBrains, Neovim, and Zed — your IDE is Helix.
  • Roo Code runs as a VS Code-compatible extension — your IDE is Helix.
  • Kilo Code runs as a VS Code-compatible extension — your IDE is Helix.
  • Zed Agent only runs inside the Zed editor — your IDE is Helix.
  • Augment Code officially supports VS Code, JetBrains, Vim, and Neovim — your IDE is Helix.
  • Amp (Sourcegraph) officially supports VS Code and JetBrains — your IDE is Helix. Use the CLI version otherwise.
  • Sourcegraph Cody (Enterprise) supports VS Code, JetBrains, and Visual Studio — your IDE is Helix.
  • Cursor CLI works in any terminal but needs an active Cursor subscription — your IDE is Helix, which is fine but the cost is tied to Cursor.
  • @codebase indexing is a Cursor-only feature, but your IDE is Helix.
  • Cursor Background Agents are dispatched from Cursor (desktop or mobile) — your IDE is Helix.
