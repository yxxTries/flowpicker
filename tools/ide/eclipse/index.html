Conflicts & caveats

  • GitHub Copilot does not officially support Eclipse.
  • Continue.dev only supports VS Code and JetBrains — your IDE is Eclipse.
  • Continue.dev does not officially support Eclipse — Copilot, Tabnine, and Codeium are the main supported options.
  • Codeium does not officially support Eclipse — use VS Code, JetBrains, Vim, or Neovim.
  • Cursor built-in only runs inside the Cursor editor — your IDE is Eclipse.
  • Cline only supports VS Code and JetBrains IDEs — your IDE is Eclipse.
  • Windsurf Cascade only runs inside Windsurf — your IDE is Eclipse.
  • Sourcegraph Cody does not officially support Eclipse — use VS Code, JetBrains, or Visual Studio.
  • Tabnine does not officially support Eclipse.
  • Amazon Q Developer does not officially support Eclipse — use VS Code or JetBrains.
  • JetBrains AI Assistant only runs inside JetBrains IDEs — your IDE is Eclipse.
  • Qodo officially supports VS Code and JetBrains — your IDE is Eclipse.
  • Supermaven only supports VS Code, JetBrains, Neovim, and Zed — your IDE is Eclipse.
  • Roo Code runs as a VS Code-compatible extension — your IDE is Eclipse.
  • Kilo Code runs as a VS Code-compatible extension — your IDE is Eclipse.
  • Zed Agent only runs inside the Zed editor — your IDE is Eclipse.
  • Augment Code officially supports VS Code, JetBrains, Vim, and Neovim — your IDE is Eclipse.
  • OpenCode is a terminal-first CLI; running it inside Eclipse works but the experience is in the embedded terminal.
  • Amp (Sourcegraph) officially supports VS Code and JetBrains — your IDE is Eclipse. Use the CLI version otherwise.
  • Sourcegraph Cody (Enterprise) supports VS Code, JetBrains, and Visual Studio — your IDE is Eclipse.
  • Cursor CLI works in any terminal but needs an active Cursor subscription — your IDE is Eclipse, which is fine but the cost is tied to Cursor.
  • @codebase indexing is a Cursor-only feature, but your IDE is Eclipse.
  • Cursor Background Agents are dispatched from Cursor (desktop or mobile) — your IDE is Eclipse.
