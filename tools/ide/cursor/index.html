Conflicts & caveats

  • GitHub Copilot does not officially support Cursor.
  • Continue.dev only supports VS Code and JetBrains — your IDE is Cursor.
  • Codeium does not officially support Cursor — use VS Code, JetBrains, Vim, or Neovim.
  • Cline only supports VS Code and JetBrains IDEs — your IDE is Cursor.
  • Windsurf Cascade only runs inside Windsurf — your IDE is Cursor.
  • Sourcegraph Cody does not officially support Cursor — use VS Code, JetBrains, or Visual Studio.
  • Tabnine does not officially support Cursor.
  • Amazon Q Developer does not officially support Cursor — use VS Code or JetBrains.
  • JetBrains AI Assistant only runs inside JetBrains IDEs — your IDE is Cursor.
  • Qodo officially supports VS Code and JetBrains — your IDE is Cursor.
  • Cursor has its own built-in AI; Supermaven may conflict with or be redundant to it.
  • Supermaven only supports VS Code, JetBrains, Neovim, and Zed — your IDE is Cursor.
  • Zed Agent only runs inside the Zed editor — your IDE is Cursor.
  • Augment Code officially supports VS Code, JetBrains, Vim, and Neovim — your IDE is Cursor.
  • Amp (Sourcegraph) officially supports VS Code and JetBrains — your IDE is Cursor. Use the CLI version otherwise.
  • Sourcegraph Cody (Enterprise) supports VS Code, JetBrains, and Visual Studio — your IDE is Cursor.
