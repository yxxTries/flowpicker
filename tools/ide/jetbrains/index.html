Conflicts & caveats

  • Cursor built-in only runs inside the Cursor editor — your IDE is JetBrains.
  • Windsurf Cascade only runs inside Windsurf — your IDE is JetBrains.
  • Zed Agent only runs inside the Zed editor — your IDE is JetBrains.
  • Cursor CLI works in any terminal but needs an active Cursor subscription — your IDE is JetBrains, which is fine but the cost is tied to Cursor.
  • @codebase indexing is a Cursor-only feature, but your IDE is JetBrains.
  • Cursor Background Agents are dispatched from Cursor (desktop or mobile) — your IDE is JetBrains.
