Conflicts & caveats

  • Google Antigravity is built around Gemini 3 Pro; Claude and recent GPT-5 models also work, but GPT-4o is not in the supported model list.
  • GitHub Copilot does not officially support Google Antigravity.
  • Continue.dev only supports VS Code and JetBrains — your IDE is Google Antigravity.
  • Codeium does not officially support Google Antigravity — use VS Code, JetBrains, Vim, or Neovim.
  • Cursor built-in only runs inside the Cursor editor — your IDE is Google Antigravity.
  • Cline only supports VS Code and JetBrains IDEs — your IDE is Google Antigravity.
  • Windsurf Cascade only runs inside Windsurf — your IDE is Google Antigravity.
  • Sourcegraph Cody does not officially support Google Antigravity — use VS Code, JetBrains, or Visual Studio.
  • Tabnine does not officially support Google Antigravity.
  • Amazon Q Developer does not officially support Google Antigravity — use VS Code or JetBrains.
  • JetBrains AI Assistant only runs inside JetBrains IDEs — your IDE is Google Antigravity.
  • Qodo officially supports VS Code and JetBrains — your IDE is Google Antigravity.
  • Supermaven only supports VS Code, JetBrains, Neovim, and Zed — your IDE is Google Antigravity.
  • Zed Agent only runs inside the Zed editor — your IDE is Google Antigravity.
  • Augment Code officially supports VS Code, JetBrains, Vim, and Neovim — your IDE is Google Antigravity.
  • OpenCode is a terminal-first CLI; running it inside Google Antigravity works but the experience is in the embedded terminal.
  • Amp (Sourcegraph) officially supports VS Code and JetBrains — your IDE is Google Antigravity. Use the CLI version otherwise.
  • Sourcegraph Cody (Enterprise) supports VS Code, JetBrains, and Visual Studio — your IDE is Google Antigravity.
  • Cursor CLI works in any terminal but needs an active Cursor subscription — your IDE is Google Antigravity, which is fine but the cost is tied to Cursor.
  • @codebase indexing is a Cursor-only feature, but your IDE is Google Antigravity.
  • Cursor Background Agents are dispatched from Cursor (desktop or mobile) — your IDE is Google Antigravity.
