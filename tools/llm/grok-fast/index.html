Conflicts & caveats

  • Trae's built-in model menu may not include Grok 4-1 Fast — Trae primarily ships with Claude/GPT/Gemini/DeepSeek.
  • Google Antigravity is built around Gemini 3 Pro; Claude and recent GPT-5 models also work, but Grok 4-1 Fast is not in the supported model list.
  • Kiro's spec mode is tuned for Claude models — Grok 4-1 Fast may work but spec-driven flows are best with Claude.
  • OpenAI Codex (VS Code) is tied to OpenAI's GPT-5.1 Codex family — Grok 4-1 Fast is not selectable inside this integration.
  • Gemini CLI is locked to Google Gemini models — your LLM is Grok 4-1 Fast.
  • Claude Code only works with Claude models — your LLM is Grok 4-1 Fast.
  • Devin uses Cognition's proprietary model internally — your selected Grok 4-1 Fast will be ignored.
  • OpenAI Codex (Cloud) runs GPT-5.1 Codex internally — your selected Grok 4-1 Fast will be ignored.
  • Jules runs Gemini models internally — your selected Grok 4-1 Fast will be ignored.
  • The Claude Code SDK is tuned for Claude models — Grok 4-1 Fast may work via the model adapter but loses Claude-specific features (thinking, prompt caching, sub-agents).
  • Lovable uses a fixed internal model — your selected Grok 4-1 Fast will be ignored.
  • Replit Agent 3 uses its own model selection internally — your selected Grok 4-1 Fast will be ignored.
