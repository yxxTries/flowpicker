Conflicts & caveats

  • Trae's built-in model menu may not include Nemotron 3 Nano Omni — Trae primarily ships with Claude/GPT/Gemini/DeepSeek.
  • Google Antigravity is built around Gemini 3 Pro; Claude and recent GPT-5 models also work, but Nemotron 3 Nano Omni is not in the supported model list.
  • Kiro's spec mode is tuned for Claude models — Nemotron 3 Nano Omni may work but spec-driven flows are best with Claude.
  • Cursor's built-in model menu may not include Nemotron 3 Nano Omni — verify it's available in your Cursor model picker.
  • OpenAI Codex (VS Code) is tied to OpenAI's hosted GPT-5 and Codex models — Nemotron 3 Nano Omni is not selectable inside this integration.
  • Gemini CLI is locked to Google Gemini models — your LLM is Nemotron 3 Nano Omni.
  • Privacy conflict: Self-hosted Nemotron 3 Nano Omni sends code to cloud @codebase (Cursor). Use local context (Continue indexing, ChromaDB, LanceDB, pgvector, Vespa self-hosted) for true privacy.
  • Claude Code only works with Claude models — your LLM is Nemotron 3 Nano Omni.
  • Devin uses Cognition's proprietary model internally — your selected Nemotron 3 Nano Omni will be ignored.
  • OpenAI Codex (Cloud) runs GPT-5.1 Codex internally — your selected Nemotron 3 Nano Omni will be ignored.
  • Jules runs Gemini models internally — your selected Nemotron 3 Nano Omni will be ignored.
  • The Claude Code SDK is tuned for Claude models — Nemotron 3 Nano Omni may work via the model adapter but loses Claude-specific features (thinking, prompt caching, sub-agents).
  • Lovable uses a fixed internal model — your selected Nemotron 3 Nano Omni will be ignored.
  • Replit Agent 3 uses its own model selection internally — your selected Nemotron 3 Nano Omni will be ignored.
