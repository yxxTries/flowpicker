Conflicts & caveats

  • Trae's built-in model menu may not include Muse Spark 1.2 (Contributor) — Trae primarily ships with Claude/GPT/Gemini/DeepSeek.
  • Google Antigravity is built around Gemini 3 Pro; Claude and recent GPT-5 models also work, but Muse Spark 1.2 (Contributor) is not in the supported model list.
  • Kiro's spec mode is tuned for Claude models — Muse Spark 1.2 (Contributor) may work but spec-driven flows are best with Claude.
  • Cursor's built-in model menu may not include Muse Spark 1.2 (Contributor) — verify it's available in your Cursor model picker.
  • OpenAI Codex (VS Code) is tied to OpenAI's hosted GPT-5 and Codex models — Muse Spark 1.2 (Contributor) is not selectable inside this integration.
  • Gemini CLI is locked to Google Gemini models — your LLM is Muse Spark 1.2 (Contributor).
  • Claude Code only works with Claude models — your LLM is Muse Spark 1.2 (Contributor).
  • Devin uses Cognition's proprietary model internally — your selected Muse Spark 1.2 (Contributor) will be ignored.
  • OpenAI Codex (Cloud) runs GPT-5.1 Codex internally — your selected Muse Spark 1.2 (Contributor) will be ignored.
  • Jules runs Gemini models internally — your selected Muse Spark 1.2 (Contributor) will be ignored.
  • The Claude Code SDK is tuned for Claude models — Muse Spark 1.2 (Contributor) may work via the model adapter but loses Claude-specific features (thinking, prompt caching, sub-agents).
  • Lovable uses a fixed internal model — your selected Muse Spark 1.2 (Contributor) will be ignored.
  • Replit Agent 3 uses its own model selection internally — your selected Muse Spark 1.2 (Contributor) will be ignored.
