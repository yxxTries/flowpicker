Conflicts & caveats

  • Cursor's built-in model menu may not include Qwen 3.6 — verify it's available in your Cursor model picker.
  • Privacy conflict: Self-hosted Qwen 3.6 sends code to cloud @codebase (Cursor). Use local context (Continue indexing, ChromaDB, LanceDB, pgvector) for true privacy.
  • Claude Code only works with Claude models — your LLM is Qwen 3.6.
  • Devin uses Cognition's proprietary model internally — your selected Qwen 3.6 will be ignored.
