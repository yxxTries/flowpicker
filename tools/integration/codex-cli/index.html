Conflicts & caveats

  • Replit has its own built-in AI Agent — external integrations like OpenAI Codex CLI cannot run inside the Replit web IDE.
  • OpenAI Codex CLI does not officially support Xcode. Use GitHub Copilot for Xcode or Direct API.
  • OpenAI Codex CLI has limited or no official Android Studio support. Use GitHub Copilot or JetBrains AI Assistant.
  • Void Editor is BYO-API-key first — OpenAI Codex CLI runs as an extension on top, which can work but isn't the intended Void workflow.
  • Lapce has a small plugin ecosystem; OpenAI Codex CLI may not have an official plugin yet.
  • Positron is VS Code-based but tuned for R/Python data science — OpenAI Codex CLI may install but is not officially supported.
  • OpenAI Codex CLI does not officially support RStudio — use direct API calls or the rstudio.cloud Copilot integration.
  • OpenAI Codex CLI does not officially support Spyder — use the direct API.
  • Cursor Mobile only runs Cursor-managed agents and background tasks — local-only integrations like OpenAI Codex CLI cannot run on the phone.
  • OpenAI Codex CLI does not officially support Eclipse — Copilot, Tabnine, and Codeium are the main supported options.
  • OpenAI Codex CLI does not officially support Apache NetBeans — Copilot and Tabnine are the main supported options.
  • @codebase (Cursor) only works with Cursor built-in integration (yours is OpenAI Codex CLI).
  • Continue's codebase indexing only works when the integration is Continue.dev (yours is OpenAI Codex CLI).
  • Windsurf codebase indexing only works with Windsurf Cascade integration (yours is OpenAI Codex CLI).
  • Aider architect mode requires the Aider integration (yours is OpenAI Codex CLI).
