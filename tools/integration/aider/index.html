Conflicts & caveats

  • Replit has its own built-in AI Agent — external integrations like Aider (terminal) cannot run inside the Replit web IDE.
  • Aider (terminal) does not officially support Xcode. Use GitHub Copilot for Xcode or Direct API.
  • Aider (terminal) has limited or no official Android Studio support. Use GitHub Copilot or JetBrains AI Assistant.
  • @codebase (Cursor) only works with Cursor built-in integration (yours is Aider (terminal)).
  • Continue's codebase indexing only works when the integration is Continue.dev (yours is Aider (terminal)).
  • Windsurf codebase indexing only works with Windsurf Cascade integration (yours is Aider (terminal)).
