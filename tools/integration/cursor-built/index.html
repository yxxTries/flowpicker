Conflicts & caveats

  • Cursor built-in only runs inside the Cursor editor — your IDE is VS Code.
  • Replit has its own built-in AI Agent — external integrations like Cursor built-in cannot run inside the Replit web IDE.
  • Cursor built-in does not officially support Xcode. Use GitHub Copilot for Xcode or Direct API.
  • Cursor built-in has limited or no official Android Studio support. Use GitHub Copilot or JetBrains AI Assistant.
  • Void Editor is BYO-API-key first — Cursor built-in runs as an extension on top, which can work but isn't the intended Void workflow.
  • Lapce has a small plugin ecosystem; Cursor built-in may not have an official plugin yet.
  • Positron is VS Code-based but tuned for R/Python data science — Cursor built-in may install but is not officially supported.
  • Cursor built-in does not officially support RStudio — use direct API calls or the rstudio.cloud Copilot integration.
  • Cursor built-in does not officially support Spyder — use the direct API.
  • Cursor built-in does not officially support Eclipse — Copilot, Tabnine, and Codeium are the main supported options.
  • Cursor built-in does not officially support Apache NetBeans — Copilot and Tabnine are the main supported options.
  • Cursor's built-in model menu may not include Llama 3 (Ollama/Groq) — verify it's available in your Cursor model picker.
  • Continue's codebase indexing only works when the integration is Continue.dev (yours is Cursor built-in).
  • Windsurf codebase indexing only works with Windsurf Cascade integration (yours is Cursor built-in).
  • Aider architect mode requires the Aider integration (yours is Cursor built-in).
