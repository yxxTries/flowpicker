Conflicts & caveats

  • Amazon Q Developer does not officially support Cursor — use VS Code or JetBrains.
  • Replit has its own built-in AI Agent — external integrations like Amazon Q Developer cannot run inside the Replit web IDE.
  • Amazon Q Developer does not officially support Xcode. Use GitHub Copilot for Xcode or Direct API.
  • Amazon Q Developer has limited or no official Android Studio support. Use GitHub Copilot or JetBrains AI Assistant.
  • Void Editor is BYO-API-key first — Amazon Q Developer runs as an extension on top, which can work but isn't the intended Void workflow.
  • Lapce has a small plugin ecosystem; Amazon Q Developer may not have an official plugin yet.
  • Positron is VS Code-based but tuned for R/Python data science — Amazon Q Developer may install but is not officially supported.
  • Amazon Q Developer does not officially support RStudio — use direct API calls or the rstudio.cloud Copilot integration.
  • Amazon Q Developer does not officially support Spyder — use the direct API.
  • Cursor Mobile only runs Cursor-managed agents and background tasks — local-only integrations like Amazon Q Developer cannot run on the phone.
  • Amazon Q Developer does not officially support Eclipse — Copilot, Tabnine, and Codeium are the main supported options.
  • Amazon Q Developer does not officially support Apache NetBeans — Copilot and Tabnine are the main supported options.
  • @codebase (Cursor) only works with Cursor built-in integration (yours is Amazon Q Developer).
  • Continue's codebase indexing only works when the integration is Continue.dev (yours is Amazon Q Developer).
  • Windsurf codebase indexing only works with Windsurf Cascade integration (yours is Amazon Q Developer).
  • Aider architect mode requires the Aider integration (yours is Amazon Q Developer).
