Conflicts & caveats

  • JetBrains AI Assistant only runs inside JetBrains IDEs — your IDE is VS Code.
  • Replit has its own built-in AI Agent — external integrations like JetBrains AI Assistant cannot run inside the Replit web IDE.
  • JetBrains AI Assistant does not officially support Xcode. Use GitHub Copilot for Xcode or Direct API.
  • @codebase (Cursor) only works with Cursor built-in integration (yours is JetBrains AI Assistant).
  • Continue's codebase indexing only works when the integration is Continue.dev (yours is JetBrains AI Assistant).
  • Windsurf codebase indexing only works with Windsurf Cascade integration (yours is JetBrains AI Assistant).
  • Aider architect mode requires the Aider integration (yours is JetBrains AI Assistant).
