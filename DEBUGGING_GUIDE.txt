MANUAL STEPS
============

If you want to debug manually:

1. Go to http://localhost:8000/templates.html
2. Open DevTools (F12)
3. Click "Use Template"
4. Look at Console tab
5. You should see messages starting with:
   - [Templates] Loading template:
   - [Templates] Selections structure:
   - [Templates] Saved to localStorage...
   - [Templates] Navigating...

6. After page loads on index.html, look for:
   - [Table] Rendering with selections:

7. If you DON'T see these messages, something is broken earlier.
8. If you DO see them, the problem is in table rendering.
